Exalate Migration Audit Tool (Jira DC)

Jira Data Center → Jira Cloud 마이그레이션 사전조사를 위한 Exalate Incoming / Outgoing 동기화 큐(Queue) 및 오류(Errors) 안전 감사 도구

Python 3.11+ Strict Read-Only Jira Data Center Exalate IssueHub 4.0 ../env Compatible

⚠️ Confidentiality & Security Warning

생성된 JSON 및 CSV 파일에는 다음 정보가 포함될 수 있습니다:

  • Jira 이슈 메타데이터 (Issue Key, Project, Summary 등)
  • 사용자 계정 정보 및 인스턴스 연결 정보
  • 원격 동기화 대상 시스템(Remote System) 주소 및 설정
  • Exalate 동기화 오류 및 스택트레이스

수집된 산출물은 기밀 마이그레이션 감사 데이터(Confidential Assessment Data)로 취급하여 안전하게 보관하세요.

📌 핵심 주의사항: Queue와 Sync Relation의 구분

REST API(syncevents, syncrequests)를 통해 수집되는 데이터는 현재 처리 대기 중이거나 진행 중인 트랜잭션(Queue)입니다.

* Outgoing Queue != 전체 Outgoing Synced Issues
* Incoming Queue != 전체 Incoming Synced Issues
  • Outgoing Queue: 현재 로컬 Jira에서 원격 인스턴스로 전송 대기 중인 이벤트
  • Incoming Queue: 원격 인스턴스에서 도착하여 로컬 Jira에 반영 대기 중인 요청
  • Error: 현재 처리 실패 및 재시도 대기 상태의 오류 트랜잭션
  • 전체 동기화된 이슈(Synced Issues / Relations): 이미 동기화되어 유지되고 있는 Issue Mapping 데이터이며, 이는 Phase 2 (Jira ActiveObjects DB 직접 조회) 단계에서 수집합니다.

🚀 주요 기능

🔒 운영 환경 Strict Read-Only

오직 HTTP GET 요청만 허용하며, POST, PUT, PATCH, DELETE 호출은 코드 레벨에서 엄격히 차단됩니다. Jira DB 쓰기 작업이 없어 무중단 운영 환경에서도 안전합니다.

⚙️ ../env 완벽 연동 & 타겟 전환

상위 디렉토리의 ../env 파일을 자동으로 인식합니다. --target OPS(운영) 또는 --target STG(검증) 옵션으로 대상 Jira DC 환경을 원클릭으로 전환할 수 있습니다.

🔑 인증 체계 분리 지원

Jira 8.14+ 권장 방식인 Personal Access Token (PAT, Bearer)과 기존 Basic Auth (Username + Password)를 클래스로 분리하여 유연하고 안정적인 인증을 지원합니다.

🛡️ HTTP 복원력 & 지수 백오프

429(Rate Limit), 500, 502, 503, 504 응답 시 지수 백오프(Exponential Backoff: 1s, 2s, 4s...)를 적용해 자동 재시도하며, 401/403/404 발생 시 명확한 원인 진단을 제공합니다.

🕵️ 탐색적 스키마 로깅 (Debug)

Exalate 버전에 따른 필드 차이를 파악할 수 있도록, 최초 API 호출 시 Status Code, Content-Type, Root Keys, Result Item Keys를 DEBUG 로그로 분석하여 기록합니다.

🎭 민감정보 자동 마스킹

로그 및 콘솔에 토큰, 비밀번호, Authorization 헤더, 쿠키, URL 내 Credential이 노출되지 않도록 ***REDACTED***로 실시간 마스킹 처리합니다.

⚙️ 환경변수 (../env) 설정 매핑

실행 위치 기준 상위 디렉토리의 ../env 파일에 정의된 변수를 자동으로 읽어옵니다. 별도의 복사 없이 기존 ../env 파일을 그대로 사용합니다.

💻 CLI 실행 방법

1. 기본 실행 (운영 Jira DC 조사)

기본적으로 JIRA_DC_OPS 설정을 사용하며 ../env 파일을 자동 로드합니다:

python main.py

2. 대상 환경 지정 (OPS vs STG)

--target (또는 --env) 플래그를 통해 검증 또는 운영 환경을 지정합니다:

# Staging DC 조사 (사내망/VPN 환경)
python main.py --target STG

# Operations DC 조사
python main.py --target OPS

3. 인증 방식 선택 (PAT vs Basic)

# Basic Auth로 명시적 실행
python main.py --target OPS --auth-type basic

# Personal Access Token(Bearer)으로 실행 (기본값)
python main.py --target OPS --auth-type pat

4. 요약(Summary)만 신속 조회 (limit=0 쿼리)

전체 상세 데이터를 다운로드하지 않고 현재 큐 및 에러 건수만 빠르게 확인합니다:

python main.py --target OPS --summary

5. 특정 큐/에러만 개별 조사

# Outgoing Queue만 수집
python main.py --target OPS --outgoing

# Incoming Queue만 수집
python main.py --target OPS --incoming

# 에러 목록만 수집
python main.py --target OPS --errors

6. 디버그 모드 (실제 Exalate API 응답 스키마 분석)

python main.py --target OPS --debug
