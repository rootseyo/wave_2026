INTRODUCTION
----------------------------

These error logs are designed to help you understand where your migration is failing and take steps to fix the errors before trying again.

The error logs are broken down per-project and include both export and import errors. Search by project key to find the log file for a project of interest. You can also refer to your Jira server logs for more export details.

This feature is still in development. Please get in touch with our support team if you have any feedback or suggestions for improvement. <https://support.atlassian.com/contact/#/>

HOW TO GET HELP
-----------------------------

We have a number of channels available to help you with your migration.

-   For more migration planning information and FAQs, visit the Atlassian Cloud Migration Center <https://www.atlassian.com/cloud-migration>
-   Have a technical issue or need more support with strategy and best practices? Get in touch. <https://support.atlassian.com/contact/#/>
-   Looking for peer advice? Ask the Atlassian Community. <https://community.atlassian.com/t5/Atlassian-Cloud-Migration/ct-p/atlassian-cloud-migration>
-   Want expert guidance? Work with an Atlassian Partner. <https://www.atlassian.com/partners>
