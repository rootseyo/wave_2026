# 에이전트 작업 지침 (AGENTS.md)

## 1. 작업 환경 정의 (Environment Role)
- **현재 환경**: **코드 작성 및 개발 전용 로컬 환경 (Development Only)**
- **제약 사항**: 본 로컬 환경에서는 실제 운영/연동 테스트 및 마이그레이션 스크립트를 직접 실행하지 않습니다.
- **역할**: 코드 작성, 수정, 리팩토링, 정적 분석 및 산출물 파일 전송 준비를 전담합니다.

---

## 2. 테스트 및 실행 워크플로우 (Testing & Execution Workflow)
모든 기능 테스트 및 실제 스크립트 실행은 별도로 구성된 **테스트/운영 환경**에서 수행해야 합니다.

### [기본 절차]
1. **코드 작성/수정**: 본 환경에서 필요한 기능 개발 및 코드 수정 완료.
2. **파일 전송 (로컬 -> 테스트 환경)**:
   - 수정된 스크립트 또는 설정 파일을 전송 도구(`send_file.py`)를 통해 전달합니다.
   ```bash
   # 예: 특정 파일 전송
   python send_file.py <전송할_파일명>
   ```
3. **테스트 환경에서 수신 및 실행**:
   - 테스트 환경에서 전달된 파일을 다운로드/복사한 후 실행 및 검증을 진행합니다.
   - 테스트 결과 피드백에 따라 본 환경에서 코드를 추가 수정합니다.

---

## 3. 에이전트 행동 수칙 (Agent Guidelines)
- 사용자가 코드 작성/수정을 요청하면 본 환경에서 코드를 완성합니다.
- 사용자가 테스트 또는 실행을 요청하거나 테스트가 필요한 상황인 경우:
  - 현재 환경이 **코드 작성 전용 환경**임을 인지하고 로컬에서 임의로 실행하지 않습니다.
  - 테스트 환경으로 파일을 복사/전송할 수 있도록 변경된 파일 목록과 전송 방법(`send_file.py` 등)을 안내합니다.
- 항상 이 규칙을 최우선으로 준수하여 작업을 진행합니다.
