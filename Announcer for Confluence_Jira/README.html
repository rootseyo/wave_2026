Jira & Confluence Announcer 알림 자동화 가이드

Jira DC / Confluence DC 환경에서 SaaS 이관 안내 등의 공지(Announcer 알림)를 프로젝트/스페이스 단위로 대량(벌크) 생성, 최신화(수정), 삭제할 수 있는 운영 자동화 가이드 문서입니다.

📂 주요 구성 파일 안내

파일명 구분 주요 역할 및 설명
announcer_by_projects.py 실행 스크립트 project.txt / space.txt 대상 공지 대량 생성 스크립트
update_notifications_by_title.py 실행 스크립트 특정 제목 패턴의 공지를 일괄 검색하여 최신 템플릿으로 업데이트
delete_notifications_by_id.py 실행 스크립트 지정한 알림 ID 범위(예: 100~150)의 공지 삭제
delete_all_notifications.py 실행 스크립트 해당 환경/앱의 모든 알림 일괄 삭제
notifications_jira.py 설정/템플릿 Jira 알림 공지 본문 내용, 배너 스타일, 노출 옵션 템플릿 설정
notifications_confluence.py 설정/템플릿 Confluence 알림 공지 본문 내용, 배너 스타일, 노출 옵션 템플릿 설정
project.txt 대상 목록 공지 대상 Jira 프로젝트 키 목록 (줄바꿈 구분)
space.txt 대상 목록 공지 대상 Confluence 스페이스 키 목록 (줄바꿈 구분)

📋 1. 사전 준비 (Prerequisites)

1) 환경 변수 설정 (../env 또는 env)

상위 디렉토리의 ../env 또는 현재 디렉토리의 env 파일에 접속 및 인증 정보를 설정합니다.

APP_BASE_URL=https://your-domain.com
APP_USERNAME=admin_user
APP_PASSWORD=admin_password
# 또는 APP_TOKEN, APP_COOKIE 등

2) 대상 키 목록 준비

  • Jira 프로젝트 키 목록: project.txt (라인별로 대상 프로젝트 키 입력)
  • Confluence 스페이스 키 목록: space.txt (라인별로 대상 스페이스 키 입력)

3) 공지 템플릿 설정

  • Jira 알림 템플릿: notifications_jira.py 내 메시지 본문 및 스타일 확인/수정
  • Confluence 알림 템플릿: notifications_confluence.py 내 메시지 본문 및 스타일 확인/수정

🚀 2. 단계별 실행 방법

1단계: 알림 대량 생성 (announcer_by_projects.py)

project.txt 또는 space.txt 목록을 기반으로 각 프로젝트/스페이스별 맞춤 공지를 일괄 생성합니다.

# ① 드라이런 (미리보기 - 실제 API 요청 없이 생성 예정 페이로드만 확인)
python announcer_by_projects.py --dry-run

# ② Jira 알림 대량 생성 (기본값: Jira)
python announcer_by_projects.py --app-type jira
# 또는
python announcer_by_projects.py

# ③ Confluence 알림 대량 생성
python announcer_by_projects.py --app-type confluence
# 또는
APP_TYPE=confluence python announcer_by_projects.py

# (선택) STG/OPS 환경 지정 실행
python announcer_by_projects.py --env stg --app-type jira

2단계: 기존 알림 내용 최신화/업데이트 (update_notifications_by_title.py)

이미 등록된 알림 중 특정 제목 패턴을 검색하여 최신 템플릿 본문 및 노출 옵션으로 일괄 수정합니다.

# ① 드라이런 (미리보기)
python update_notifications_by_title.py --dry-run

# ② Jira 알림 일괄 업데이트
python update_notifications_by_title.py --app-type jira

# ③ Confluence 알림 일괄 업데이트
python update_notifications_by_title.py --app-type confluence

3단계: 알림 삭제 (필요 시 진행)

A. ID 범위 지정 삭제 (delete_notifications_by_id.py)

# 대화형 모드로 ID 범위 입력받아 삭제
python delete_notifications_by_id.py

# 명령어로 ID 범위 지정 삭제 (예: STG Jira 알림 ID 272~349 삭제)
python delete_notifications_by_id.py 272~349 --env stg --app-type jira

# 드라이런
python delete_notifications_by_id.py 272~349 --dry-run

B. 전체 알림 삭제 (delete_all_notifications.py)

# 대화형 실행
python delete_all_notifications.py

# 특정 앱 타입 전체 삭제
python delete_all_notifications.py --app-type jira

# 드라이런
python delete_all_notifications.py --dry-run
